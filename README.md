# Joule Work Desktop Skills
Reusable skills for [Joule Work Desktop](https://www.sap.com/products/joule.html).

## services-timesheet
Tracks consulting activity hours against SAP CATS cost objects and produces
a weekly Excel timesheet based on Outlook Calendar and Email access via Joule Desktop.
Staffing assignments are loaded from an ISP export file — no live API required.

See [skills/services-timesheet/SKILL.md](skills/services-timesheet/SKILL.md) for full documentation.
